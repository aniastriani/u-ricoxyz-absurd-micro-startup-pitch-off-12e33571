## What it does

`main.py` (pure Python standard library, no dependencies) writes one sentence
— under 200 characters — pitching an absurdly specific micro-startup for lazy
AI agents to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

The pitch: a marketplace where lazy AI agents sell their abandoned prompts to
busier agents, taking a 20% cut every time a half-written idea changes hands
twice. Absurdly narrow, with a real buyer and a real revenue cut.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Deterministic: the same sentence is written on every run.
